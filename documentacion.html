Guardar documentos: limitaciones del diálogo de guardado

Al pulsar Guardar, el editor intenta abrir el diálogo «Guardar como» del sistema para que el usuario elija la carpeta y el nombre del archivo .json. El nombre propuesto es el título del documento. Este diálogo depende de la API showSaveFilePicker (File System Access API), que no está disponible en todos los navegadores ni en todas las situaciones.

Compatibilidad por navegador

Navegador Comportamiento al guardar
Chrome, Edge, Opera (escritorio) Se abre el diálogo «Guardar como» y el usuario elige dónde guardar.
Firefox No admite la API. El archivo se descarga directamente en la carpeta de descargas. Para que pregunte dónde guardar, hay que activar en sus ajustes «Preguntar siempre dónde guardar los archivos».
Safari No admite la API. El archivo se descarga en la carpeta de descargas.
Navegadores móviles No admiten la API. Se usa la descarga normal del navegador.

Contexto seguro obligatorio

Aunque el navegador sea compatible, la API solo funciona en un contexto seguro:

  • Funciona al abrir el editor desde http://localhost:8000 o desde una dirección https://.
  • No funciona al abrir index.html directamente como archivo (file://).
  • No funciona al acceder desde otro equipo por HTTP sin cifrar (por ejemplo, http://192.168.1.20:8000).

En estos casos el editor usa automáticamente la descarga normal.

Otros detalles

  • Si el usuario cancela el diálogo, no se guarda nada y no se muestra ningún error.
  • Si el diálogo no se puede abrir por cualquier otro motivo, el editor deja un aviso en la consola y recurre a la descarga normal.
  • El navegador solo permite abrir el diálogo como respuesta directa a un clic del usuario, por eso no se puede lanzar el guardado en archivo de forma automática.
El guardado automático del editor no se ve afectado: el documento se sigue guardando en el almacenamiento local del navegador (localStorage) mientras se escribe. Ese guardado pertenece a cada navegador y equipo; para conservar o mover un documento hay que guardarlo con el botón Guardar.
