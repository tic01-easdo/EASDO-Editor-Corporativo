Servidor local del proyecto

  1. Abre PowerShell o Terminal en la carpeta del proyecto.
  2. Ejecuta:

    3. Mac

    python3 -m http.server 8000

    PC

    py -3 -m http.server 8000

Direcciones en el navegador:

Abrir Editor

GitHub

Subir cambios al repositorio de GitHub (en la carpeta del proyecto):

  1. Descarga lo último que hayan subido los demás:
    git pull
  2. Prepara los archivos cambiados:
    git add .
  3. Guarda el cambio con un mensaje que lo describa:
    git commit -m "Qué has cambiado"
  4. Envíalo a GitHub:
    git push
Abrir repositorio
